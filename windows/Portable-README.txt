ChatGPT To Codex portable Windows bundle

1. Extract the whole folder before running it.
2. Launch "ChatGPT To Codex.exe" from the extracted folder.
3. The bundle includes its own Node runtime under runtime\node.exe.
4. Keep the folder structure intact. The launcher expects start-chatgpt.ps1, dist, node_modules, and runtime beside the EXE.
5. Loopback mode needs no public tunnel. ChatGPT web needs an externally reachable HTTPS connector.
6. A Tailscale Serve URL is tailnet-private. ChatGPT web requires Tailscale Funnel or another public HTTPS endpoint.
7. Treat Owner Token values like passwords and never include them in screenshots or bug reports.
